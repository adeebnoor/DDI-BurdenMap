# DDI BurdenMap

Reproducibility repository for the manuscript **“Mapping drug–drug interaction burden: robust hub structure across candidate, reference, and independently curated interaction networks.”**

This repository contains the reproducibility materials used for the Frontiers in Pharmacology submission, including the candidate-pair inputs, analysis scripts, derived outputs, and a public-source reconstruction script for DDInter 2.0.

## Reproducibility archive

`Hub_DDI_Reproducibility_SAFE.zip` is the submission-ready reproducibility archive. It deliberately does **not** redistribute DDInter source files. Instead, `code/prepare_ddinter_from_public.py` reconstructs the required DDInter-derived analysis inputs from the public DDInter download pages while preserving DDInter’s original licensing terms.
