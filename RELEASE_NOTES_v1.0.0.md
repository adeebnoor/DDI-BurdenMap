# DDI-BurdenMap v1.0.0 — submission reproducibility release

- Candidate-network analysis for 16,316 filtered candidate DDI pairs among 1,114 drugs.
- Construction-reference network analysis and mechanism-stratified topology.
- Independent DDInter reconstruction and severity/permutation workflow without redistributing DDInter source or derivative pair-level data.
- Fixed random seeds and pinned Python environment.
- GitHub-facing visual summaries and machine-readable aggregate outputs.
- Submission-version manuscript and supplementary information in Markdown source form.

This release is prepared for Zenodo archival to mint the DOI used in the Frontiers submission metadata.
